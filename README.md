## Featured Support Cases

SIGNATURE - End-to-End Access Investigation Remote user cannot access SharePoint. Investigated across Entra sign-in logs, Conditional Access evaluation, device compliance state, Intune assignment, licence assignment, group membership and SSO token. Eight-step investigation with tools documented at each stage.

Case 022 - PIM Activation Governance Gap Privileged role activation reviewed against governance controls. Investigated through PIM role settings and the resource audit log. Default settings identified as permitting activation without MFA, justification or approval. Remediated by enforcing MFA, justification, named approver and assignment expiry, with the corrected configuration confirmed in the tenant.

Case 009 - Defender Risk Score Blocking Access Active threat detected on managed device by Defender for Endpoint. Risk score elevated above compliance threshold. Device automatically blocked from Conditional Access. Threat investigated and remediated. Compliance restored without manual policy changes.
