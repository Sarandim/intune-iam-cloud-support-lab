# Case 003 - Conditional Access MFA Challenge on Untrusted Location Sign-in

**Type:** Incident
**Priority:** P3 - Single user affected, access available after MFA completion
**Impact:** Single user, Maria Costa, unexpected MFA prompt on sign-in
**Urgency:** Normal - access retained, user required guidance to proceed
**Affected CI:** User account maria.costa@DalModernWorkplaceLab.onmicrosoft.com
**Assignment group:** IT Support - Identity and Access

## Summary
Maria Costa reported an unexpected MFA prompt when signing in to Office 365 
from a network outside the organisation's trusted location range. Investigation 
confirmed the prompt was triggered by Conditional Access policy CA001, which 
requires MFA for all sign-ins from untrusted network locations.

## Investigation
1. Reviewed sign-in logs in Entra under Users, Maria Costa, Sign-in logs and 
identified a sign-in event from an IP address outside the defined trusted 
location range.
2. Confirmed CA001 - Require MFA Outside Trusted Locations was applied to 
the event and evaluated as requiring MFA.
3. Verified the user is a member of IT Support Staff group, which is in scope 
for CA001.
4. Confirmed a preceding sign-in from the trusted Netherlands network location 
completed without an MFA challenge, validating the trusted location exclusion 
is functioning correctly.

## Resolution
1. Confirmed to the user that the MFA prompt was legitimate and generated by 
CA001 enforcing additional verification from untrusted network locations.
2. Directed the user to approve the number matching notification in Microsoft 
Authenticator to complete sign-in.
3. Confirmed successful sign-in following MFA completion via sign-in logs.

## Customer update
Maria Costa - the verification prompt you received is legitimate. It is 
generated by a security policy that requires multi-factor authentication for 
sign-ins from networks outside the organisation's trusted locations. Approve 
the request in your Microsoft Authenticator app to complete sign-in. Contact 
IT support if you are unable to approve the request.

## Root cause and prevention
CA001 correctly identified the sign-in as originating from an untrusted 
network location and enforced MFA as designed, no remediation required. 
The user will be included in security awareness communications confirming 
when MFA prompts are expected.
